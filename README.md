# uOLibraryProxyBtn
Adds a button to Google Scholar to access articles via uOttawa Library EZproxy.

## Installation
1. Install [Tampermonkey](https://tampermonkey.net/) in your browser.
2. Click [here](https://github.com/FrzMtrsprt/uOLibraryProxyBtn/raw/refs/heads/main/main.user.js) to install the user script.
> [!NOTE]
> You need to submit a proxy access request if you are outside Canada. If not, you should see a message prompting you to submit an access request when clicking any of the links.

## Usage
- Simply search for publications in Google Scholar and click the "Proxy" button on the right. You should be able to view the full content.
